## Reset Commands
- Safe local reset and reseed:
  ```bash
  npm run reset
  # Or directly:
  node src/seed/reset.js
  ```
- Reseed without resetting state:
  ```bash
  npm run seed
  # Or directly:
  node src/seed/seed.js
  ```
- *Production Safety Guard*: `npm run reset` blocks execution if `NODE_ENV === 'production'` unless `ALLOW_PROD_RESET=true` is explicitly specified.

## Ticket Review Packet

- Review URL and environment.
- Login credentials (`admin@car-neon-city-racer.local` / `ChangeMe!12345`).
- Exact input/sample data to use.
- Expected result for the ticket.
- Automated checks that ran (`npm run lint`, `npm test`, `npm run build`).
- Screenshot/log/evidence references generated by the agent loop.
